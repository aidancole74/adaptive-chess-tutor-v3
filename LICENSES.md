## GPL distribution implications

- Anyone who distributes this app (including hosting the built `dist/` publicly) distributes Stockfish and must comply with GPL-3.0: provide the complete corresponding source (this repository, including build scripts) under GPL-3.0 and keep `public/engine/COPYING.txt`.
- Because the engine is loaded in the same web application, this project treats the whole app as GPL-3.0-or-later rather than arguing that a Web Worker is a separate program.
- The Lichess data is CC0; no attribution is legally required, but sources are credited in the UI (puzzle links) and here.
- If you need a non-GPL build, remove `public/engine/` and the engine-dependent features (game analysis, play-outs against the engine, sparring); everything else works without it.
